# ❤️ Heart Disease Prediction using Machine Learning

## Part 2 – Predictive Modeling Pipeline

---

# Project Overview

This project focuses on building a complete Machine Learning pipeline to predict whether a patient has heart disease based on clinical and medical attributes.

The project demonstrates an end-to-end machine learning workflow including:

- Data preprocessing
- Feature engineering
- Train-test splitting
- Feature encoding
- Feature scaling
- Model training
- Model evaluation
- Cross-validation
- Hyperparameter tuning
- Model comparison
- Final model selection

The objective is to develop a reliable classification model that can assist in identifying patients at risk of heart disease.

---

# Business Question

Can we accurately predict whether a patient has heart disease using clinical information such as age, sex, chest pain type, cholesterol level, blood pressure, ECG results, maximum heart rate, and other medical features?

A prediction system can help healthcare professionals identify high-risk patients early and support timely medical intervention.

---

# Problem Type

## Classification Problem

The target variable contains two classes:
0 → No Heart Disease
1 → Heart Disease
